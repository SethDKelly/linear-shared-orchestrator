2. **004-C — Completeness and independent behavioral ownership.** Audit C2/C3/R-06 end-to-end intrinsic value, missing guards/actions, correction, query, history, and actor/basis credibility. Challenge RD-15 without assuming `verified=true` is evidence.
3. **004-D — Independence, genericity, and boundary alternatives.** Check abstract parameter use, peer-concept coupling, local authority, and retain/split/merge/reframe/generalize/reject alternatives; classify future synchronization seams for Phase 005 and extrinsic inclusion questions for Phase 006.
4. **004-E — Adversarial modularity and re-specification.** Independently challenge counterexamples, stale revision applicability, false permission/completion, silence, contested grounds, privacy, accessibility, and any revised concept's full Phase 003 behavioral contract. Material identity changes explicitly reopen Phase 003.
5. **004-F — Reconciliation, canonical owners, and independent exit.** Reconcile decisions, supersession, unresolved evidence and phase handoffs; obtain fresh independent exact-head exit review and separate sponsor decision before Phase 005.

These letters are a *proposal*, not a fixed sequence authorized for execution. Entry review may split, reorder or remove workstreams based on evidence.
