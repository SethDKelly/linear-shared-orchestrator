## Independence and scope tests
**Versus C2:** A question about evidence can be challenged, but it does not itself constitute an attempt or an execution outcome. If R-06 requires a native C2 action to record an attempt, independence fails. Shared abstract grounds are permissible as inputs only; they cannot be automatically trusted.

**Versus C3:** A sponsor's explicit permission is neither an attempt nor substantiation of outcome. R-06 cannot grant permission, replace local security decisions or clear S-40.

**Versus C6:** An articulate story about work is not the facts of the work. R-06 must support outcome distinctions without a narrative or presentation surface. C6 stays unpromoted.

**Versus C1/S-81:** The behavior must be expressible without ReviewReceipt, provider rotation, orchestration, controller state or a workflow engine. A list of status labels alone does not prove distinct identity. An attributable work attempt and supported result must have concept-level semantics.
